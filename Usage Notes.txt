FabScan Development-Machine Notes
=================================

These notes describe the FabLabPlasma development PC. They are examples, not
universal FabScan requirements.

LinuxCNC realtime CPU on this machine
-------------------------------------
CPU 5 is reserved for LinuxCNC realtime work. FabScan must not be pinned to CPU 5.

Verify the LinuxCNC realtime thread with tools appropriate to your installation.
The development machine has historically used rtapi_app on CPU 5 with realtime
priority configured by LinuxCNC.

FabScan launch command used for current development/testing
-----------------------------------------------------------

cd ~/projects/FabScan
source venv/bin/activate
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
taskset -c 3,4 nice -n 15 ionice -c3 python3 fabscan.py

Why this launch is used here:
- keeps BLAS/OpenMP helper libraries single-threaded
- pins FabScan away from the LinuxCNC realtime CPU
- lowers normal scheduler priority
- gives FabScan idle-class disk I/O priority

Do not copy the CPU numbers blindly. Use CPU affinity that matches your own
LinuxCNC realtime configuration.

Current v0.6 alpha tracing notes
--------------------------------
- Real belief following is bounded step-and-settle, not continuous velocity jog.
- Planner recommended IPM is diagnostic/logged only for real motion.
- Physical M6 runs force recording ON.
- Current development-machine M6 safety defaults:
    Hard max move     0.035 in
    Min planner conf  45 %
    Min look-ahead    0.045 in
- Proven conservative lateral correction starting point on this machine:
    Follow Step  0.030 in
    Deadband     0.003 in
    Gain         0.35
    Max Correct  0.003 in

These are development-machine values, not universal recommendations.
